# Banking Credit Card Customer Churn Analysis

## Project Overview
This project analyzes customer churn patterns for a banking 
credit card dataset containing 10,127 customers. The goal is 
to identify key characteristics of churned customers and provide 
actionable insights to help the bank improve customer retention.

## Business Questions Answered
- What is the overall churn rate?
- Which gender churns more?
- Which income group is most at risk of churning?
- Which card type has the highest churn?
- What age group churns the most?
- How does transaction behavior differ between churned and retained customers?
- What are the key risk indicators for churn?

## Tools Used
- Python (Pandas, Matplotlib, Seaborn) — data analysis and visualizations
- Jupyter Notebook — interactive analysis environment
- Power BI — interactive dashboard
- GitHub — version control and portfolio

## Dataset
- Source: Kaggle — Credit Card Customer Churn Dataset
- Records: 10,127 customers
- Features: 21 columns after cleaning

## Key Insights
- Overall churn rate is 16.07% — above the industry concern threshold
- Female customers churn more despite being the larger customer base
- Customers earning less than $40K represent the highest churn segment
- Blue card holders account for the majority of churned customers
- Customers aged 40-50 churn the most
- Churned customers have significantly lower transaction amounts — 
  a key early warning signal for the bank
- Inactivity alone is not a reliable churn predictor
